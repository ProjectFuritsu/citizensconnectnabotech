# To-do, and where to change things

For anyone working on the Panabo City Citizen's Portal. Two parts:

1. **[Where to change what](#1-where-to-change-what):** which file to edit for common changes. Most changes are in `src/Data/`, not in the code.
2. **[To-do list](#2-to-do-list):** open work, each item with the files involved and what to do.

**Keeping this file current:**
- **Starting an item:** put your name after the title, e.g. `(@juan)`.
- **Finishing one:** tick it (`- [x]`), move it to [Recently done](#recently-done) with the date, and update any README it mentions.
- **Finding new work:** add it under the right heading, in the same format.

Last reviewed: 21 October 2026.

---

## 1. Where to change what

### Data and settings: all in `src/Data/`

Each folder has a README with its file format; [src/Data/README.md](src/Data/README.md) lists where everything comes from. In VS Code, hover over a field for help; mistakes are underlined in red.

| I want to… | Change | Read first |
| --- | --- | --- |
| Add, remove or reorder a navbar or footer link | `pages` or `tools` in [Site/site.config.json](src/Data/Site/site.config.json) | [Site/README.md](src/Data/Site/README.md) |
| Put a link in the **Services** or **Transparency** dropdown | `"group": "Services"` on the page or tool | [Site/README.md](src/Data/Site/README.md) |
| Grey out a link with a "Soon" label, or hide it | `"disabled": true` or `"hidden": true` | [Site/README.md](src/Data/Site/README.md) |
| Change the "Popular" shortcuts under the home page search | `popularGuides` in `site.config.json` | [Site/README.md](src/Data/Site/README.md) |
| Change the site name, address, or the title and description shown in search results | `site` in `site.config.json` | [Site/README.md](src/Data/Site/README.md) |
| Update the emergency numbers | [Site/hotlines.json](src/Data/Site/hotlines.json); update `lastUpdated` too | [Site/README.md](src/Data/Site/README.md) |
| Add or edit a service guide | [Guides/guides.json](src/Data/Guides/guides.json) | [Guides/README.md](src/Data/Guides/README.md) |
| Add a budget year | `Budget/years/<year>.json` | [Budget/README.md](src/Data/Budget/README.md), [METHODOLOGY.md](src/Data/Budget/METHODOLOGY.md) |
| Update procurement data | Run the scripts in [scripts/procurement/](scripts/procurement/); they write to `Procurement/` | [Procurement/README.md](src/Data/Procurement/README.md) |
| Add a year of COA audit reports | `Audit/reports/<year>/` and [Audit/reports.json](src/Data/Audit/reports.json) | [Audit/README.md](src/Data/Audit/README.md) |

### Look and code

| I want to… | Change |
| --- | --- |
| Change colors, fonts, corner radius or chart colors | [src/Theme/theme.css](src/Theme/theme.css); the rules are in [src/Theme/DESIGN.md](src/Theme/DESIGN.md) |
| Change how pesos, dates, percentages or fees are written | [src/Theme/display.js](src/Theme/display.js) |
| Build or restyle a page | Use the shared components in [src/Components/](src/Components/), listed in DESIGN.md "Shared components" |
| Change the navbar, dropdowns, hotline bar or footer | [src/Components/NavBar.jsx](src/Components/NavBar.jsx), [src/Components/Footer.jsx](src/Components/Footer.jsx) |
| Change the logo | [src/Components/Logo.jsx](src/Components/Logo.jsx), [src/Theme/logo.svg](src/Theme/logo.svg), and the icons in `public/` |
| Add a new page | Create it in `src/Pages/<Name>/`, add a route in [src/Routes/AppRoute.jsx](src/Routes/AppRoute.jsx), then add it to `pages` in `site.config.json` |
| Change how data is read or prepared | The service for that folder in [src/Services/](src/Services/) |
| Change page titles, link previews or structured data | `usePageMeta` in each page, and [src/SEO/](src/SEO/) |
| Change the sitemap or robots.txt | Generated by [vite.config.js](vite.config.js) from `site.config.json` and the guides; nothing to edit by hand |

**Commands:** `npm run dev` (local site), `npm run lint`, `npm run build`.

## 2. To-do list

### Content and data

- [ ] **Re-check the emergency hotlines.** They were last checked on 18 February 2026. Confirm each number against official announcements, then update `lastUpdated` in [src/Data/Site/hotlines.json](src/Data/Site/hotlines.json); the hotlines page shows it.

- [ ] **Update the site's search description.** `site.title` and `site.description` in [src/Data/Site/site.config.json](src/Data/Site/site.config.json) only mention service guides, not the Budget and Procurement pages. These are what Google and link previews show. Keep the title under ~70 characters and the description under ~160.

- [ ] **Add the 2025 budget** once COA publishes the 2025 Annual Audit Report. Follow "Adding a new year" in [src/Data/Budget/README.md](src/Data/Budget/README.md).

- [ ] **Add the 2025 COA audit report** when it's released. See [src/Data/Audit/README.md](src/Data/Audit/README.md).

- [ ] **Fill the procurement gaps:** 2023 and 2025 (all quarters), and 2026 Q4 once published. Steps are in "How to update" in [src/Data/Procurement/README.md](src/Data/Procurement/README.md); update its "Known gaps" table when done.

- [ ] **Add the budget extractor as a project script** (`scripts/budget/`), so new years are extracted and checked the same way as 2021–2024. [METHODOLOGY.md](src/Data/Budget/METHODOLOGY.md) describes what it must do: read the SCBAA, convert the numbers, recompute both "Difference" columns, and check the totals.
  - **Excel years:** [scripts/procurement/xlsx.cjs](scripts/procurement/xlsx.cjs) already reads `.xlsx` files.
  - **PDF years:** a PDF text reader is needed; pdf.js was used for 2024.

- [ ] **Community tools marked "Soon":** Market Prices, Citizens Project Directory, Citizens Volunteers Hub, Disaster Preparedness Guide, Open Data Hub and More Tools.
  - **When one launches:** check its `url` in `site.config.json` (the current addresses may be placeholders), then remove `"disabled": true`.
  - **"More Tools":** decide whether it's needed at all.

### Code and design

- [ ] **Load each page only when it's visited.** The main JavaScript file is about 540 KB, so the home page also downloads the Budget, Procurement and Guide Hub code. The build warns about this.
  - **How:** use `React.lazy` and `<Suspense>` in [src/Routes/AppRoute.jsx](src/Routes/AppRoute.jsx).
  - **Done when** the build no longer warns about chunk size.

- [ ] **Explain the budget figures on the page itself.** Add a short "Where these numbers come from" section to [src/Pages/Budget/BudgetPage.jsx](src/Pages/Budget/BudgetPage.jsx), summarizing [METHODOLOGY.md](src/Data/Budget/METHODOLOGY.md) for residents:
  - the source;
  - what Original, Final and Actual mean;
  - how the numbers were checked.

- [ ] **Run lint and build automatically** on every pull request (for example with GitHub Actions). Both pass today.

- [ ] **Resolve the ESLint version mismatch.** `eslint-plugin-react-hooks` 7 officially supports ESLint up to 9, but the project uses ESLint 10, so `npm install` needs `--legacy-peer-deps`. Lint works; update the plugin once a version supporting ESLint 10 is out.
